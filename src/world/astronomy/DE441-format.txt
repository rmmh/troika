JPL DE441 NATIVE ASTRONOMY MEDIA, VERSION 1

Original source: https://ssd.jpl.nasa.gov/ftp/eph/planets/ascii/de441/
Description: https://ssd.jpl.nasa.gov/planets/eph_export.html
Theory: Park et al. (2021), AJ 161:105, doi:10.3847/1538-3881/abd414
https://ssd.jpl.nasa.gov/doc/Park.2021.AJ.DE440.pdf

Coverage is -1999-01-01 00:00 TDB through 3001-01-01 00:00 TDB exclusive,
using proleptic Gregorian dates and astronomical years (0 = 1 BCE). These are geometric ICRF3 coordinates.
TDB is not UTC, TT, or Earth-rotation UT1. No leap-second or historical
DeltaT conversion is implicit. Do not describe this as apparent sky position:
light-time, aberration, observer position and frame orientation are separate.
Planetary-system barycenters are explicitly identified in the manifest.
Earth = EMB - MoonGeocentric/(1+EMRAT). SunGeocentric = Sun - Earth.
EMRAT is the original header constant, not a rounded textbook mass ratio.

The committed .d441 files are compact, immutable coefficient digests. Builds
and tests are offline and need no preparation or source downloads. Each source
coefficient was initially rounded to whole meters, then rounded to the nearest
400 meters with ties away from zero. This retains the original Chebyshev series
and its time intervals; no orbital-element replacement or position table is used.

scripts/astronomy/import-de441.py regenerates the original audited whole-meter
media from pinned JPL ASCII. Those .bin intermediates are ignored by Git.
scripts/astronomy/pack-de441.py generates the compact digests from them.
`npm run astronomy:prepare` explicitly downloads any missing ASCII caches under
/tmp, regenerates intermediates and checks byte-for-byte digest reproducibility.
`npm run astronomy:check` verifies the committed compact files offline.
The source manifest pins original sources and intermediate hashes; the runtime
manifest pins compressed files, uncompressed lengths and native media hashes.
Only explicit --refresh updates either manifest or original test oracles.

Transport format (before gzip)
Bytes0..3 ASCII D441; byte4 version1; bytes5..8 uint32LE quantum400 meters;
bytes9..494 contain the original 243-cell native header as signed16LE.
The remaining bytes are coefficient columns, ordered by body, axis, then
Chebyshev degree. Each column has recordCount*piecesPer32Days values in time
order. Values are signed integer multiples of400 meters. Store third finite
differences, initializing previous value/first difference/second difference to
zero at each column. Signed integers use zigzag (v>=0:2v; v<0:-2v-1), then
base128 unsigned varints, least-significant groups first, high bit=continuation.
Gzip has an empty filename and zero modification time for reproducibility.

The host verifies the transport hash, decompresses, integrates each column
three times and expands coefficients to whole meters. It reconstructs the
native record/body/polynomial directories and padding and checks the native
SHA256 before mounting. Host decoding performs no astronomical evaluation.

Binary files are signed little-endian Int16 trytes, padded to 243-cell blocks.
The block device presents these immutable media directly; there is no FAT.

Archive index1 corresponds to de441--2000.d441, index21 to de441-0.d441, and
index51 to de441-3000.d441. All archives mount at physical unit1; native RAM
3990 requests an archive index. The first archive includes the otherwise
unexposed year -2000 so its complete year index remains regular. Files overlap by a record at century boundaries when
necessary. Last volume contains only year 3000. Every file fits 9841 blocks.
Block 0 cells 0..15:
  441, formatVersion1, firstYear, yearCount, recordCount,
  firstRecordDayOffsetFromJanuary1, directoryBlock1, directoryEntryWidth2,
  bodyCount11, recordDays32, coefficientQuantumMeters1, lengthRadix5,
  reserved0, reserved0, reserved0, reserved0.
At cell16, each year has two cells: recordIndex and dayWithinRecord at January1.
There is an additional end-year entry. Add zero-based day-of-year to its day,
divide by32, and add that quotient to recordIndex. This avoids large day counts.
Record directory starts at absolute cell243, with two cells per record:
absolute block number and cell offset within that block. Records are contiguous.
Each record begins11 offsets, relative to its first cell, to body data.
Body order, coefficient counts and number of pieces/32days are in the manifest.
Each body's pieces are chronological; each piece contains X, Y, Z polynomials.
A polynomial of n coefficients starts ceil(n/5) headers. Each header packs five
coefficient lengths, each0..4, in base5 least-significant first. Unused lengths
are zero. Then follow those coefficients in ascending Chebyshev order, each
as length signed balanced-base19683 limbs little-endian. Length0 means zero.
Native expansion converts whole meters to integer millimeters. The normalized
argument x is round(3^27 * (2*(t-pieceStart)/pieceDays - 1)); evaluate with
multiword Clenshaw and nearest rounded products divided by3^27.

The source audit covers57082 records,4109904 axis polynomials and46578912
coefficients. Since |T_k(x)|<=1, the sum of absolute coefficient perturbations
bounds every time within a polynomial, not only sampled times. The compactor
measures that sum for EVERY polynomial relative to the whole-meter source
media, then adds the original audited4.923453m per-axis quantization bound.
It also includes normalized-argument and native Clenshaw rounding bounds.
Each body's worst per-axis error is recorded in the runtime manifest. Combining
these bounds in Euclidean norm, including Earth derivation and Sun subtraction,
must stay below10000 meters; packing fails if that budget is exceeded.
This bounds representation error relative to the supplied original DE441,
not physical trajectory uncertainty. Historical Earth rotation is separate.
The native disk still stores coefficients in whole meters, so its unit field
remains1; transport precision is400 meters, and native arithmetic remains in
millimeters. Decimal display digits are arithmetic precision, not accuracy.

Tests independently decode all records, verify all hashes/indices/year entries,
compare5358 dates (every year, arbitrary times and century boundaries) against
high-precision Decimal evaluation of original unquantized ASCII, and check an
independent official Horizons Earth vector at J2000. Native arithmetic tests
also use81 actual-coefficient endpoint/midpoint cases. Test fixtures are oracles,
not a runtime position lookup table; guest execution evaluates the disk series.
